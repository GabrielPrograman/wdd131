Website Planning Document

Final Project Blueprint

Site Name

Proposed Name: Venezuela Temple Travel

Description: I chose this name because it clearly states the geographical focus and purpose of the website It is designed to be a comprehensive travel guide and resource hub for church members planning trips, caravans, or personal visits to the temple in Venezuela, ensuring they have all the logistics in one place.

Site Purpose

The purpose of this website is to provide and organized, user-friendly platform that assists individuals and families in planning their visits to the temple. The site will offer up-to-date schedule summaries, local transportation recommendations, nearby lodging options, and essential guidelines for patrons, reducing stress and improving the overall spiritual travel experience

Target Audience Scenarios

Scenario 1

I am organizing a stake youth caravan to visit the temple next month. Where can I find a list of approved lodging options or housing near the temple site?

Scenario 2

What are the current operational hours for ordinance sessions, and is there a specific contact number to schedule group sessions?

Color Schema

The selected colors provide a trustworthy, serene, and clean aesthetic appropriate for a temple-focused service website

Primary Dark Blue (#1a365d) Used for Header backgrounds, main headings, and strong branding elements.
Secondary Slate Blue (#2b6cb0) Used for subheadings, navigation highlights, and borders.
Accent Teal/Green (#2f855a) Used for interactive states, call-to-action buttons, or highlights.
Background Light (#f7fafc) Used for the main site background and card containers to ensure contrast.

Typography

Montserrat (Heading Font)

Usage Applied to paragraphs, list items, and general body text. It offers exceptional legibility on digital screens, making it perfect for long reading blocks and logistical tables.

Open Sans (Body Font)

Wireframes Layout Plan

The home page will follow a responsive design grid ensuring clarity across devices:

Mobile View Layout:

  • Header: Single column with full-width dark blue block containing the Site Name and a hamburger menu to toggle button.
  • Hero Section: A descriptive header statement followed by a single main Call-to-Action.
  • Main Grid: Content stacked vertically into a single column (Information blocks, features, cards).
  • Footer: Standard dynamic metadata block containing copyright and last modified lines.

Desktop View Layout:

  • Header: Extended row layout with Site Name branding on the left and a horizontal navigation bar on the right.
  • Main Content: features a clean 3-column CSS Grid displaying the different travel services (Lodging, Transport, Session Schedules).
  • Sidebar: a small quick-links side box containing important safety alerts or fast scheduling numbers.
